# Compiled workload provenance

The raw `.wasm` files are the shipped original programs. The C sources, SQLite source identity and portable build scripts reproduce their executable content. Development probe `proof.json` and `module-manifest.json` files record the initial mechanism experiments, using their own transform export names and hashes; they are not current Forkwake snapshot/cache schema artifacts.

Run `node cli.mjs demo --out <new-directory>` to generate actual current-policy SQLite outcome evidence and a portable Forkwake workspace. `npm test` compares current engine continuations with original raw controls. The public release's SQLite outcome asset is generated by the installed package.
