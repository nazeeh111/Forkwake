# Origin inspector delivery

Deepen the existing JavaScript execution-fork product. At a real suspended
decision, show its active native-interpreter stack, navigate bound source lines,
compare origins across sibling futures and save/reopen the same evidence.
This is caller context, not causal data flow, coverage, variable provenance or
complete asynchronous ancestry. No standalone flagship or universal-debugger claim.

## Authority and existing behavior

Isolated `feat/origin-inspector` worktree starts at current main60f3bb8. Preserve
the exact 0.3 original interpreter/template/bridge and all SQLite/Wasm behavior.
Original QuickJS vendor sources stay pristine. No credentials, paid API, account
inventory, PIVOT, external posting or blocked-security validation.

## Mechanism and trust boundary

An optional separately identified interpreter uses native public C error/stack
APIs from the proved mechanism. No source rewrite or global Error wrapper.
Generated engine compatibility copy escapes guest-controlled function names in
backtrace text so names cannot manufacture apparent source frames. Preserve
the original vendor and exact generation patch/hash. No user getter execution.
Compile original bridge-origin.c with the existing WASI SDK34, no compiler in
the end-user source-loading workflow.

Trace output is bounded to 4095 UTF-8 bytes, plus terminator. Full temporary
backtrace creation can consume additional bounded guest allocator memory.
Tracing is opt-in and is not universally observationally pure. If metadata
cannot be allocated, report unavailable while allowing the decision to proceed
where possible; test against uninstrumented controls under quota pressure.

Origin decoding requires the exact recognized normalized engine identity and
source slot. Report source SHA256 and pending ordinal. Original `script.js`
frames may navigate bound source lines; dynamic `<input>` frames remain unmapped.
Function labels are escaped interpreter display names, not authenticated lexical
identifiers. Columns are interpreter coordinates, not exact token positions.
Incomplete clipped frames cannot be mapped. Completed nodes label their last
captured decision context, never claim that its old callers are currently active.
Clear unrelated/stale origins on raw effects; preserve existing state integrity.

## Contracts / ownership

- Core: `loadScriptModule(source,{name,origin:false})`, metadata `originTracing`
  boolean and `originWarning`; recognize both original and trace engines. Attach
  bounded `report.origin` with state captured/unavailable/truncated, source hash,
  raw text and frames {functionName,filename,line,column,sourceBound}. Core owns
  loader/report/fixture, new engine build/manifest/bridge and origin.test.mjs.
- Parent: service accepts optional strict boolean origin on sequence-script;
  CLI capture/explore adds boolean --origin only with --script. Continuation and
  portable reopen infer tracing from retained module identity. Add an original
  multi-function Promise/closure demo with independently checked controls;
  current faulty/corrected examples and all legacy CLI/API requests still work.
- Studio: opt-in checkbox + Origin example. Origin evidence tab shows actual
  caller frames, raw text, source-bound numbered excerpt and explicit metadata
  limits. Captured-source excerpt always uses session module source, never edited
  draft. Compare both selected and right node origins honestly. Missing/legacy/
  non-JavaScript cases have explicit useful states. Own only web/futures files.

## Acceptance and delivery

Unchanged original engine bytes/source; malicious names/getters/dynamic eval;
closures/Promise continuation line checks against independent V8; original VM
output/result/event histories; actual sibling/import origins; truncated and
memory-pressure states. Relevant CLI/API/browser journeys and portable new-key
reopen. Fresh consequential review, final three hosted gates, actual published
package/source/assets verified before delivery. No duplicated old audit or
unapproved community post. Version0.4 is a coherent incremental release, not a
claim that the full GitHub mission is achieved.
