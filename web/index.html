What can I run?

WebAssembly is a portable compiled program format. The ABI is the exact interface between the guest and this runtime. Forkwake supports one owned pending event and these imported callbacks:

env.pre_cut(i32, i32) → void
env.pending_effect(i32, i32, i32, i32) → i32
env.post_cut(i32, i32) → void

Required exports: run(i32) → i32, memory, header_address() → i32, and asyncify_capacity() → i32. Optional: _initialize() → void. Memory must be owned, unshared wasm32 with an explicit maximum no greater than 32 MiB. Continuation storage must be aligned and bounded.

The saved state includes guest memory, mutable globals, and the suspended call stack. It does not clone a native process, files, sockets, or external services.
