01 / START

An order is waiting.

The compiled SQLite example reserves inventory, takes payment, then dispatches. Its intentionally faulty policy may ship an unpaid order.

Run your own compatible program

A closed WebAssembly program owns its memory and uses Forkwake’s callback interface: env.pre_cut(i32,i32), env.pending_effect(i32,i32,i32,i32) → i32, and env.post_cut(i32,i32). It exports run(i32) → i32, memory, header_address() → i32, and asyncify_capacity() → i32. The optional initializer is _initialize(). Upload limit: 8 MiB. Owned, unshared wasm32 memory must have an explicit maximum of at most 32 MiB. This runtime saves guest memory, globals, and suspended stack frames. Files, sockets, native processes, and external services are outside this interface.
